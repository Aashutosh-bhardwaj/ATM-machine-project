#  ATM Machine Project (Python)

##  Project Overview
The **ATM Machine Project** is a Python-based console application that simulates the basic operations of an Automated Teller Machine (ATM). It allows users to securely access ATM services using a PIN and perform essential banking transactions such as checking account balance, withdrawing money, and depositing money.

The project is developed using Python and demonstrates fundamental programming concepts such as conditional statements, loops, exception handling, variables, and built-in modules.

##  Problem Statement
Managing basic banking transactions manually can be time-consuming. This project provides a simple ATM simulation that allows users to perform common banking operations through a menu-driven interface.

It also includes a daily withdrawal limit and automatic transaction receipts to make the simulation more realistic.

## ✨ Features

- 🔐 **PIN Authentication:** Allows users to access the ATM using a PIN.
- 💰 **Check Balance:** Displays the current account balance.
- 💸 **Cash Withdrawal:** Allows users to withdraw money from their account.
- 📥 **Cash Deposit:** Enables users to deposit money into their account.
- 📊 **Daily Withdrawal Limit:** Restricts withdrawals according to the predefined daily limit.
- 🧾 **Transaction Receipt:** Generates a receipt after successful deposits and withdrawals.
- 🕒 **Date & Time:** Displays the transaction date and time.
- ⚠️ **Error Handling:** Handles invalid inputs and incorrect PIN entries.
- 🚪 **Exit Option:** Allows users to safely exit the ATM system.

## 🚀 How to Run the Project

**Step 1:** Clone the repository.

```bash
git clone https://github.com/Aashutosh-bhardwaj/ATM-machine-project.git
```

**Step 2:** Open the project folder.

```bash
cd ATM-machine-project
```

**Step 3:** Run the Python file.

```bash
python "ATM machine profect-.py"
```

**Step 4:** Enter the PIN when prompted and select an option from the ATM menu.
